# TODO List Application

## Overview
The **TODO List Application** is a web-based task management system developed using **Spring Boot**. It allows users to easily add, edit, mark, and delete tasks, helping them stay organized and focused on their to-dos. The app features a simple, intuitive interface for managing personal tasks, making it perfect for productivity and task tracking.

## Features
- **Create Tasks:** Add new tasks to your to-do list with a title and description.
- **Mark as Completed:** Mark tasks as completed when they are done.
- **Edit Tasks:** Modify task details, including title and description, as needed.
- **Delete Tasks:** Easily remove tasks from the list once they are no longer needed.
- **Simple UI:** Clean, user-friendly interface for quick task management.
- **Spring Boot Backend:** Efficient backend logic powered by Spring Boot for handling CRUD operations.
- **Database Integration:** Uses an embedded database (e.g. MySQL) to persist tasks.

## Tech Stack
- **Spring Boot:** The core framework used for building the back-end logic.
- **Spring Data JPA:** Manages interactions with the database using JPA repositories.
- **MySQL:** Relational database (H2 for embedded or MySQL for production) to store tasks.
- **Bootstrap:** Used for styling and making the UI responsive and clean.
